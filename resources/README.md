# Resources

This directory contains the default assets expected by the WAG scripts:

- `kg/`: wearable knowledge graph nodes and edges.
- `query_set/`: generated query set and experiment q-id files.
- `processed_dataset/`: processed wearable dataset tables.
- `relationship_dict.json`: precomputed relationship statistics.

Before public redistribution, verify that all included datasets and derived
artifacts are compatible with the intended release license.
